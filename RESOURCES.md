# Resources

- [Raft paper](https://raft.github.io/raft.pdf) — primary description of terms, elections, replicated logs, and majority commit. This project implements a small educational subset.
- [Python asyncio streams](https://docs.python.org/3/library/asyncio-stream.html) — official reference for `start_server`, `open_connection`, `StreamReader`, and `StreamWriter`.
- [Antithesis Python SDK](https://antithesis.com/docs/reference/sdk/python.md) — official SDK overview for assertions, randomness, lifecycle events, local output, and assertion cataloging.
- [Antithesis test commands](https://antithesis.com/docs/product/writing_tests/test_templates/test_composer_reference.md) — when `parallel_driver`, `anytime`, and `eventually` commands run.
- [Antithesis event logs](https://antithesis.com/docs/reference/event_logs.md) — fields attached to application, assertion, workload, and fault events.
